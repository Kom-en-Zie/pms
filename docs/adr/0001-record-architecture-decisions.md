# 0001. Record architecture decisions

- Status: Accepted
- Date: 2026-11-25

## Context

PMS is built and maintained by volunteers who come and go. Without a written record, the reasons
behind the architecture get lost and decisions get reopened again and again.

## Decision

We record significant architectural decisions as lightweight ADRs in `docs/adr/`, using the
template in [the ADR index](README.md).

## Consequences

- New contributors can learn why the system looks the way it does.
- A pull request that changes an architectural decision includes a new or superseding ADR.
